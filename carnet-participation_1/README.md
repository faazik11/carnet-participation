# Carnet de participation

Petite appli web pour suivre la participation des élèves en classe : +1 / −1 par séance, historique par date, totaux, fiche par élève.

- Fonctionne sur téléphone, s'installe sur l'écran d'accueil et marche hors connexion.
- Les données restent **sur le téléphone** (aucun serveur, aucun prénom envoyé en ligne).
- Onglet **Élèves → Sauvegarde** : exporter / restaurer un fichier `.json`, ou exporter un CSV pour un tableur.

## Installer sur le téléphone

- **iPhone (Safari)** : ouvrir le lien → bouton Partager → « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvrir le lien → menu ⋮ → « Installer l'application » / « Ajouter à l'écran d'accueil ».

## Mettre à jour

Modifier les fichiers, puis changer `VERSION` dans `sw.js` pour que les téléphones récupèrent la nouvelle version.
